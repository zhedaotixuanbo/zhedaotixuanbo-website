「这道题选啵」网页预览 —— 使用说明
============================================

本文件夹是把整个 Astro 站点构建打包后的【可预览版本】。
没有任何依赖、不需要安装环境（只要你电脑装了 Node.js 即可），
原项目源码未被改动。

--------------------------------------------
一、启动预览（任何设备都能看）
--------------------------------------------
1. 双击本文件夹里的「启动预览.bat」。
2. 会弹出一个黑色命令行窗口，并自动用浏览器打开预览页。
3. 窗口里会显示两行地址，例如：
     本机：      http://localhost:4321/
     局域网设备：http://192.168.x.x:4321/
   - “本机”地址：当前这台电脑用。
   - “局域网设备”地址：手机、平板、同一 WiFi 下的其他电脑，
     用这个地址即可直接打开预览，无需任何额外设置。

--------------------------------------------
二、在手机 / 其他设备上查看
--------------------------------------------
1. 确保手机和这台电脑连接同一个 WiFi/局域网。
2. 在手机浏览器里输入上面显示的“局域网设备”地址。
3. 如果打不开，多半是 Windows 防火墙拦截了端口：
   - 在开始菜单搜索“Windows Defender 防火墙”→ 高级设置
     → 入站规则 → 新建规则 → 端口 → TCP → 特定端口填 4321
     → 允许连接 → 完成。
   - 或临时关闭防火墙测试一次。

--------------------------------------------
三、停止预览
--------------------------------------------
直接关闭那个黑色命令行窗口即可。

--------------------------------------------
四、修改端口
--------------------------------------------
默认端口 4321。若被占用，可在「server.js」里把
  const PORT = Number(process.env.PORT) || 4321;
中的 4321 改成别的数字，保存后重新双击 bat 即可。
也可用环境变量临时改：在命令行里 set PORT=4400 再运行 node server.js。

--------------------------------------------
五、文件夹里都有什么
--------------------------------------------
- index.html        首页（及其它页面在 about/、posts/、archive/ 等子目录）
- _astro/           样式、脚本、字体、优化后的图片
- assets/、favicon/、pio/、gallery/  等站点静态资源
- server.js         预览用的小型静态服务器（全网卡可访问）
- 启动预览.bat      双击启动
- 使用说明.txt      本文件

--------------------------------------------
六、说明
--------------------------------------------
- 这是“构建产物”的预览，适合查看最终网页效果。
- 若要修改网站内容，请回到原项目改源码后重新构建。
- 项目根目录下的 dist 文件夹是构建原始产物，可删除；本「网页预览」文件夹才是给你用的成品。
